# Banking & HFC SQL Practice Project

## Overview

This project provides a practical SQL Server database based on banking and Housing Finance Company (HFC) operations. It includes 10 related tables, sample datasets, an Entity Relationship Diagram (ERD), and 75+ SQL practice questions with solutions ranging from beginner to advanced levels.

## Purpose of Using This Data

The purpose of this dataset is to simulate real-world banking and housing finance operations and develop practical SQL skills. It helps learners understand how customer information, bank accounts, transactions, loan applications, repayments, collateral, and credit scores are connected in a relational database.

This dataset can be used to:
- Analyze customer accounts and transaction activity.
- Evaluate loan portfolios, repayments, and outstanding loan amounts.
- Generate branch-wise and customer-wise financial reports.
- Identify customer credit profiles and assess lending patterns.
- Practice SQL queries used in reporting, business analysis, and financial data analytics.
- Build a strong foundation for SQL interviews and data analyst roles.

## Key Features

- Banking and housing finance database schema.
- 10 interconnected tables with primary and foreign keys.
- Sample data for customers, accounts, transactions, loans, and payments.
- ERD illustrating table relationships.
- SQL queries covering aggregation, joins, subqueries, CTEs, views, and set operators.
- Advanced analytics using ROLLUP, CUBE, GROUPING SETS, and window functions.

## Most Valuable SQL Topics

- **Joins:** INNER JOIN, LEFT JOIN, RIGHT JOIN.
- **Aggregation:** GROUP BY, HAVING, aggregate functions.
- **Advanced Grouping:** ROLLUP, CUBE, GROUPING SETS, GROUPING(), GROUPING_ID().
- **Subqueries:** Correlated and non-correlated subqueries.
- **CTEs:** Common Table Expressions and recursive CTEs.
- **Window Functions:** ROW_NUMBER(), RANK(), DENSE_RANK(), LAG(), LEAD(), running totals, and moving averages.
- **Views:** Creating reusable queries for reporting.
- **Set Operators:** UNION, UNION ALL, INTERSECT, and EXCEPT.
- **Financial Analysis:** Loan performance, customer activity, branch performance, and repayment analysis.

## How to Use This Project

1. Install Microsoft SQL Server and SQL Server Management Studio (SSMS).
2. Execute the database setup SQL script to create the tables and initial sample data.
3. Run the additional INSERT scripts in order to add more sample records.
4. Explore the ERD to understand the relationships between tables.
5. Practice the SQL questions and compare your queries with the provided solutions.

## Disclaimer

This is a practice and learning project using sample data. It is not an official banking database and should not be used for real financial transactions or lending decisions.
